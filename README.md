## Overview

**X Finder** is an innovative application designed to search for user profiles across the internet using just a username. This Flutter-based app, with a robust Python backend, allows users to effortlessly find digital footprints across various platforms. The app is currently in the testing phase and is available for testing via Apple TestFlight.

X Finder is simple, efficient, and secure, making it an essential tool for anyone who needs to locate online profiles quickly.

---

## Key Features

- **Username Search**: Enter any username to search across multiple platforms for user profiles.
- **Real-Time Data**: Instant, real-time results with minimal latency.
- **Cross-Platform Support**: Seamlessly integrates data from several online platforms.
- **Available on TestFlight**: Test the application and provide feedback directly from TestFlight.

## Requirements

To run the application locally, you will need the following:

- **Flutter SDK**: `>=2.19.3 <3.0.0`
- **Dart SDK**: `>=2.19.3 <3.0.0`
- **Python**: For backend server integration (Refer to the backend repository for setup instructions).

### Dependencies

The app relies on the following core Flutter dependencies:

- `flutter_linkify`: Parse and linkify text for clickable links.
- `http`: For making HTTP requests to interact with the backend.
- `provider`: State management made easy.
- `url_launcher`: Opens URLs from within the app.
- `flutter_svg`: For rendering scalable vector graphics (SVGs).
